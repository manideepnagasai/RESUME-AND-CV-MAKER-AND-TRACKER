What is PaperTrail, and how to use it

One offline workspace for the whole job switch: build an ATS-safe resume and an academic CV, preview exact A4 pages, tailor with JD keyword match, check resume health, snapshot versions, track applications with reminders, and export PDF / DOCX / TXT / JSON in your saved style.

First time here? follow these four steps in order
1
Start from a clean page

Press “Reset to clean page” so nothing old mixes with your learning. Confirmation protects you; samples can be reloaded anytime.

2
Load the sample data

You get a finished resume + academic CV, saved versions, applications and live reminders — everything populated so every button has something real to show.

3
Take the tour, then experiment

The 12-step tour highlights each tool in place. Afterwards change anything in the samples (text, templates, spacing, exports) — they are disposable.

4
Reset again and go real

Clear the samples, then fill your own details in Build → run JD Match & Health → save a Master version → export. Your data never leaves this browser.

Daily workflow

  1. Build a master per type (Resume / CV toggle — samples are different per type).
  2. Save a Master version with notes and tags.
  3. Tailor per job: paste the JD into JD Match, mirror keywords, fix Health flags.
  4. Save updates that version (with warning) or Save-as creates a new one.
  5. Export PDF (vector, selectable) / DOCX+TXT / per-version ZIP bundle.
  6. Log the application with version used, follow-up date and notifier reminder; work the bell daily.

The Resume Field Guide

How recruiters read, what ATS parses, and how company types differ. Read once, use the checklist every time.

1 BUILD2 TAILOR3 SAVE4 APPLY5 FOLLOW UP

01How it gets read

ATS parse → six-second recruiter skim → hiring-manager deep read. Design for all three.

02Anatomy

  • Contact: name largest, title, email, phone, city, links. No photo.
  • Summary: years + strengths + one numbered proof + target.
  • Skills grouped with JD spelling; experience reverse-chronological; education; certs.
  • CV adds Publications, Talks, Teaching, Scholar/ORCID, interests.

03Bullet formula

Action verb + what you did + measurable result
Weak"Responsible for managing the backend API."
Strong"Redesigned checkout API (Node.js, Redis), cutting p95 latency 61% at 3x traffic."

04Company types

05ATS rules

  • Single column, standard fonts and headings, no tables/graphics carrying info.
  • Month YYYY dates; mirror keywords verbatim (JD Match helps).
  • Direct PDF keeps selectable text; DOCX for portals that demand Word.

06Length

  • Resume 1 page (<7 yrs) else 2; CV 2–4.
  • Margins ≥ 0.5in every page; body 10–12pt; check Pages preview breaks and the Health score.

07Mistakes

  • One generic resume everywhere; duty bullets; infographic templates; skill bars; wrong doc type; typo in the company name.
